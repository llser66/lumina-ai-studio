## 核心验证

- 匿名访问、跨账号任务与图片权限、CSRF、Origin、错误输入、上传格式和大小限制。
- 同一请求编号返回原任务；改变参数拒绝；多线程竞态下不会超额预留次数。
- 真实 LangGraph 执行、持久化检查点重新打开、原图保存后的归档恢复、未知结果不重试、不释放次数。
- OpenAI SDK 的 generate / edit 请求格式、文本优化与审核接口、错误分类、网络超时、SDK 不隐式重试。
- 背景工作池启动和关闭、私有图片下载、手动核对结果、归档恢复次数上限。
- 浏览器注册 / 退出 / 会话恢复、模板复用、参数与草稿恢复、上传与未配置服务状态。
- 隔离浏览器测试里的生成 → 下载 → 收藏 → 编辑 → 任务时间线。
- 丢失已接受请求的响应后，刷新并带原参考图和排除描述重新提交，仍只有一个任务。
- 退出后，延迟返回的历史请求不会把原账号的私有记录恢复到界面。
- 模型配置不回显密钥、凭证账户绑定加密、跨连接密文移植被拒绝、主密钥丢失不静默替换。
- 模型连接和默认用途按用户验证，撤销连接不回退到共享服务器密钥。
- OpenAI 直接 OAuth 与 Codex 订阅 OAuth 分流，回调成功与令牌交换分阶段诊断；状态错误、HTTP 401、缺少权限和网络失败不泄露原始回调或响应体。
- 网页授权的设备代码 / 手动回调输入 / 完成 / 取消 / 退出登录取消，令牌不会进入配置 API；重新授权会创建新会话。
- DeepSeek 与千问 Key 绑定到各自的官方接口；视觉输入、参考图传递和模型目录能力由 pi-ai SDK 调用验证。
- 用户自定义及千问工作空间地址每次操作前重新解析，固定公网 IP、保留 TLS 主机校验并拒绝重定向。
- 真实 Node 私有桥接启动、并发请求分派、正常关闭；pi-ai 实际图像实现的认证、比例、一次调用和错误分类。
- API Key、文本、视觉模型与供应商订阅配置的浏览器端到端流程；状态失败可清除旧链接并安全重试。
- 网页配置保存后刷新仍保留，并驱动 LangGraph 中固定的生图模型；手机端配置无横向溢出。

浏览器流程使用真实应用、数据库和 LangGraph，供应商由测试专用依赖注入替身替代；SDK 协议测试使用 HTTP MockTransport。测试服务强制空 OpenAI 密钥，测试数据位于独立临时目录。正式入口不提供模拟供应商开关。
